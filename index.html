help center
1About accounts
This section provides information about NexaTrade accounts.
2What is transaction volume?
Transaction volume is the simulated amount used in a demo trade or operation.
3Why transfer funds?
Transfers in this build move simulated balances between demo account sections.
4What are futures?
Futures are contracts linked to the future value of an asset. NexaTrade's current interface is a simulation and does not execute real futures contracts.
5Why can converted amounts change?
Displayed conversion values can vary with the illustrative market rate used by the demo.
6Why identity authentication?
The current identity flow is a self-built identity check. It is not regulatory KYC.
7What are frozen assets?
A frozen amount is a simulated balance temporarily unavailable while a demo operation is active.
8What are the demo trading rules?
Use only fictitious funds and demo codes. No real deposit, withdrawal or guaranteed return is provided.
